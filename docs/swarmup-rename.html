#SwarmUp rename: name inventory

Agent Ops becomes SwarmUp, with the domain swarmup.tech (AO-0195). This page lists every class of old name in the engine repo, how often it occurs, and the final new name. The other AO-0195 tasks (code rename, migrations, repo rename, website) work from the name table.

Status: final. Dawid accepted every row of the name table on 2026-11-09 (AO-0198, ID#01M703BENW97K8GEJ8E9DVD44S: "ok, go"). The Final column is the name each AO-0195 task uses. Review found two AGENT_OPS_* desktop variables after the accept; row 11 maps them under the accepted SWARMUP_* prefix.

#How the counts were made

  • Tracked files on claude/ao-0198 (base d69e2d49), with git grep -P, package-lock.json left out.
  • "Outside the store" leaves out .agent-ops/ (7,607 files of task history). The rename moves that folder; it does not rewrite past events.
  • Counts are files / hits. Code paths are examples, not the full list; rerun the grep to get it.

#Migrations (AO-0200)

Each migration runs once, never replaces data at the new place, and logs to migrations.log in the user config folder.

Data When How
Store folder (rows 6, 7) swarmup migrate, by a person Renames .agent-ops/ to .swarmup/ and commits it as an ops: store commit. A clone that pulls it moves unpushed files and .ops/ along
User config (row 8) First use Copy; the old file stays
swarmupd state (row 9) swarmupd start Rename, not copy: it holds tens of thousands of files. Stops an old swarmupd through its opsd.json first
App id, install (12-15) Installer nsis.guid stays the Agent Ops GUID, so the installer upgrades in place
User data, sign-in (5, 18) First start of the app Copies %APPDATA%\Agent Ops to %APPDATA%\SwarmUp; renames the sign-in entry, keeping --ops-cwd
Storage keys (row 18) Read swarmup.* keys, falling back to agent-ops.* until written

Kept on purpose:

  • The store move is a command, not automatic: a build from before the rename cannot read .swarmup/, so update every machine that shares a store before you move it.
  • An updated install keeps its install folder and the PATH record under HKCU\Software\Agent Ops. Moving the folder during a silent update would also need the PATH entry and the sign-in entry moved inside the installer. New installs go to Programs\SwarmUp.
  • File names inside the state folder (opsd.json, opsd.lock, opsd.log) and the update feed repo: agent-ops stay. The feed changes with the repo rename.
