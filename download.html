Release notes on GitHub

Before you install

  • Windows 10 or 11. The desktop app ships for Windows today; on macOS and Linux, run the command-line tool and the orchestrator from source (see the install guide).
  • Git, and at least one coding agent from your AI provider, signed in: today Claude Code or Codex.
  • The installer is not code-signed yet, so Windows SmartScreen asks first: choose More info, then Run anyway.

Next: the install guide walks you from the installer to your first agent task. Every release, with its notes, is on GitHub Releases.
